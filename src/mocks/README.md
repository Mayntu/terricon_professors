# Демонстрационные данные

Мок-сервисы и фикстуры ещё не созданы. Здесь будут адаптеры, реализующие контракты
из `services/contracts.ts`, и полностью вымышленные данные для трёх ролей.

Правила следующего этапа:

- Явно обозначать demo-режим; переключатель роли не называть безопасной авторизацией.
- Не использовать реальные персональные данные, пароли и токены.
- Держать состояние заявок, истории и уведомлений в одном mock-источнике.
- Поддержать воспроизводимый сброс данных и переход Employee → Manager → Employee.
- Возвращать реалистичные loading/empty/error/conflict состояния по контракту.
- Не подменять ошибку реального сервера успешным mock-ответом.
- Ответ AI либо подкреплён подготовленным источником, либо имеет `kind: 'no-answer'`.

Текущие страницы не импортируют mocks и не создают демо-сессию.
