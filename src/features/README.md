# Функциональные модули

Сейчас здесь только модели предметной области, без экранов и бизнес-логики.

- `identity` — роли, будущая серверная сессия, официальный профиль.
- `leave` — заявка, решение и история переходов.
- `academy` — курс и прогресс.
- `assistant` — ответ с источниками или честное отсутствие ответа.
- `notifications` — уведомления со структурированной целью перехода.

По мере реализации добавлять в соответствующий модуль `components/`, `hooks/`
и нужные функции модели. `pages/` собирает эти модули в экраны, `layouts/`
отвечает за общую навигацию. Manager и HRAdmin — рабочие пространства поверх
доменов, а не копии моделей Employee.

Модели не импортируют React, страницы, мок-данные и транспорт. Компоненты получают
данные и действия через props/feature hooks; HTTP и mock-адаптеры живут отдельно.
Не создавать пустые абстракции и глобальное хранилище до появления задачи.
