# From Request to Result · финальный ролик

Сцена после третьего слайда: `/#outro`. Отдельный режим для экспорта: `/?render=outro` — холст без контролов, paused timeline, 1920×1080.

## Компоненты

- `CinematicOutro.tsx`: предварительная загрузка локальных PNG и шрифтов, player, клавиатура, reduced motion, cleanup.
- `FilmCanvas.tsx`: общий холст; `RoadScene`, `RequestScene`, `FlowScene`, `ConnectedScene`, `BrandResolve` — визуальные части.
- `Truck.tsx`: собственная SVG-графика, без сторонних логотипов и растровых моделей.
- `timeline.ts`: единая 30-секундная GSAP timeline. 0/5/10/15/20/25 секунд — метки сцен; переходы перекрываются. Контекст очищается при выходе и изменении reduced motion.
- `paths.ts`: совместимые SVG path-команды для интерполяции сети в знак из основного продукта (`src/components/brand/Wordmark.tsx`).
- `config.ts`: формат, главы, локальные assets, типизированный контроллер экспорта.
- `outro.css`: композиция 16:9 и интерфейс плеера. Движущимися свойствами владеет GSAP; CSS-анимаций, случайности и таймеров в изображении нет.

`window.__JANA_OUTRO__`: `duration`, `seek(seconds)`, `play()`, `pause()`, `time()`. `seek` останавливает timeline и фиксирует время. Контроллер удаляется при размонтировании. React обновляет таймер HTML-плеера; изображение задаётся общей timeline. В экспортном режиме нет покадровых React state updates.

## Бизнес-сценарий

9 PNG в `public/assets/outro/` сняты с реального QA React/FastAPI/PostgreSQL. Отпуск один и тот же во всех состояниях; руководитель подтверждает его на сервере. До подтверждения маршрут светлый, затем зелёный и с текстом «Согласовано». HR не показан обязательной станцией. Academy — ранее завершённый курс; AI — ответ по статье и открытый оригинальный источник. Визуальная анимация не отправляет запросов и не имитирует live-изменения БД. Фура — только художественная метафора.

## Рендер

`npm run render:outro` собирает проект, запускает собственный сервер 5184 и три вкладки Chrome. Для каждого кадра задаётся `n / 30`, затем снимается PNG. Изображения передаются FFmpeg по порядку через image2pipe: H.264, CRF 18, yuv420p, BT.709, 900 кадров, без аудио. Медленный рендер не меняет движение. Последний кадр имеет время 899/30; видео длится ровно 30 секунд. Неподвижный финал начинается после 27.55 с.

Выбран покадровый GSAP/Playwright вместо Remotion, чтобы сохранить одну реализацию визуальных состояний. Это детерминированная сборка, а не realtime-видеозапись окна. Тест сравнивает SHA-256 PNG при повторном поиске времени, после перемотки и в новой вкладке. Бинарная идентичность между разными ОС/версиями Chrome и FFmpeg не обещается.

Ссылки на официальную документацию: [GSAP seek](https://gsap.com/docs/v3/GSAP/Timeline/seek()/), [FFmpeg image2pipe](https://ffmpeg.org/ffmpeg-formats.html#image2pipe).
