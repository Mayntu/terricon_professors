# Финал JanaМен · From Request to Result

Готовый файл: [jana-from-request-to-result.mp4](jana-from-request-to-result.mp4). Открывается обычным видеоплеером; основной HR-проект и backend для просмотра не нужны.

Формат экспорта: 1920×1080, 16:9, 30 FPS, 30 секунд, 900 кадров, H.264/yuv420p, BT.709. Без аудиодорожки. В финале — Бондарев Владислав и Хуснуллил Даниил, без CTA.

Проверено 17.10.2026: декодированы 900 кадров; чёрных/пустых кадров — 0; длительность — 30 с. Первое и последнее изображения просмотрены. MP4 открывается и воспроизводится в Chrome; переход к 29.96 с работает без ошибки. Рендер занял 228 с. Все 15 браузерных тестов прошли.

## Файлы проверки

- `render-report.json` — параметры и время фактического экспорта.
- `verification.json` — результат декодирования всех кадров, длительность, чёрные кадры и неподвижность последних двух секунд.
- `mp4-browser-check.json` — проверка воспроизведения и перемотки самого MP4 в Chrome.
- `qa-report.json` — 15 браузерных тестов и сборки презентации/основного проекта.
- `first-frame.png`, `last-frame.png` — кадры, извлечённые из MP4.
- `storyboard/` — 15 опорных кадров общей GSAP timeline.

Проверка браузерного интерфейса проведена в Chrome под Windows на 1920×1080, 1440×900 и 1366×768. Физический проектор, Safari и Firefox не проверены. UI снят на вымышленных QA-данных; это художественный ролик о существующих сценариях, не запись live-операций.

HTML-версия: `npm.cmd run dev` из `presentation`, затем http://localhost:5180/#outro. В презентации запуск — после третьего слайда, кнопка ▷ или →. Space — пауза, R — повтор, F — fullscreen, ← — возврат.

Повторный рендер: `npm.cmd run render:outro` (установка FFmpeg описана в [README](../README.md)). MP4 исключён из Git как генерируемый файл: для переноса скопируйте его отдельно либо повторите рендер. Источники кадров и сама анимация сохранены в репозитории.
